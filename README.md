# CS2 Nade Cheat Sheet

A personal cheat sheet of Counter-Strike 2 grenade lineups (smokes, molotovs, flashes, HEs) for Mirage, Dust 2, Nuke, Inferno, Ancient, Anubis and Cache, with videos, aim points, map radars and callouts.

All lineups, videos, screenshots, radars and callouts come from **[csnades.gg](https://csnades.gg)** and stream from their site. Go there to support them.

Open the page: https://errorpl.github.io/cs2-nades/ (on a phone: Share → Add to Home Screen).

Favourites are saved in each person's own browser (☆ next to a nade; ⭐ Manage to share or import a list).
